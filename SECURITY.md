# Security Policy

## Supported versions

The `main` branch of this portfolio is the supported release line.

## Reporting a vulnerability

Email **sanjaydt13@gmail.com** with:

- page or component affected
- description of the issue
- steps to reproduce where relevant

Please do not open public issues for sensitive findings.

## Practice notes

- Do not commit API keys, tokens or credentials
- Prefer mailto or server-side form handlers that keep secrets in environment variables
- Do not upload confidential employer artefacts into this repository
- Keep dependencies updated and review `npm audit` findings before release
