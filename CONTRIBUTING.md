# Contributing

This repository is a professional portfolio. Prioritise factual integrity and confidentiality.

## Workflow

1. Create a feature branch
2. Update structured content in `src/content/` before UI copy where possible
3. Keep case-study outcomes associated with the correct engagement
4. Label illustrative, representative or sanitised material explicitly
5. Run `npm run validate` before opening a pull request

## Content rules

- Do not invent experience, metrics, platforms or technical ownership
- Do not add employer logos, confidential screenshots or interviewer names
- Do not claim advanced Power BI, SQL or Databricks development unless verified
- Do not imply endorsement by any employer

## Code rules

- Prefer server components
- Use client components only for interaction, animation or WebGL
- Clean up GSAP/ScrollTrigger contexts
- Provide accessible HTML alternatives for canvas and charts
